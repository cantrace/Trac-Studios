Bilgisayarında Docker Desktop açıkken terminalde veya proje klasöründe şu komutu çalıştır:

docker compose up

Sunucu açıldığında http://localhost:27016 adresinde CS 1.6 Web sunucun canlıya geçecektir.

Arkadaşlarınla oynamak için: Bilgisayarının Yerel IP adresini (örn: http://192.168.1.50:27016) yukarıdaki çubuğa yazın ve bağlanın!
